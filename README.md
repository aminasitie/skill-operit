# Skill Operit

Koleksi lengkap skill dan kemampuan AI Operit untuk membantu menyelesaikan berbagai tugas.

## Daftar Fitur

- **Multistep UI Automation**: Mengendalikan antarmuka pengguna secara otomatis.
- **Command Execution**: Menjalankan perintah shell dan scripting.
- **File Management**: Manajemen file dan direktori canggih.
- **Memory System**: Sistem memori extended untuk konteks jangka panjang.
- **Web Integration**: Akses web dan scraping.
- **AI Capabilities**: Generasi gambar, analisis data, dan kode.

## Instalasi

File ini dioptimalkan untuk integrasi dengan Operit Assistant.
